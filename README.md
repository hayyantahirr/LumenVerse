🚀 Getting Started

1️⃣ Clone the Repo
git clone https://github.com/yourusername/lumenverse.git
cd lumenverse

2️⃣ Install Dependencies
npm install

3️⃣ Set Up Firebase

Create a Firebase project.

Enable Authentication and Firestore Database.

Add your Firebase config in a .env file.

Example .env:

VITE_API_KEY=yourapikey
VITE_AUTH_DOMAIN=yourapp.firebaseapp.com
VITE_PROJECT_ID=yourprojectid
VITE_STORAGE_BUCKET=yourapp.appspot.com
VITE_MESSAGING_SENDER_ID=senderid
VITE_APP_ID=appid

4️⃣ Run the Project
npm run dev
